# Frontend (React + Vite + TypeScript + Tailwind)

This folder contains the frontend skeleton for the Dashboard.

Install dependencies and run in development:

```bash
cd frontend
npm install
npm run dev
```

Default dev server: http://localhost:3000

Environment:
- `VITE_API_URL` — base URL to the backend API (defaults to http://127.0.0.1:8000)
